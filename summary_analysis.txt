SUMMARY METHODS EVALUATED
================================================================================

1. event_frames_log

   - Frame count: 2-19 frames (low)
   - Model: GPT-5

2. keyframes_log_parsed
   - Uses: Keyframes + parsed/structured log data

   - Model: GPT-5

4. raw_video
   - Uses: Full video analysis (no log data)
   - Frame count: 159-184 frames (high)
   - Model: GPT-5

================================================================================
KEY FINDINGS
================================================================================

1. ACCURACY LEADER: event_frames_log
   - Highest average accuracy: 78.1%
   - Most consistent performance across videos
   - Achieved one PERFECT score (100% on Video 2)
   - Benefits from both frame selection and structured log data

2. MOST COST-EFFECTIVE: event_frames_log
   - Lowest average token usage: 4,653.5 tokens
   - Uses 73% fewer tokens than raw_video
   - Best cost-efficiency ratio: 59.6 tokens per accuracy point

3. WORST PERFORMER: raw_video
   - Lowest average accuracy: 68.4%
   - Highest token usage: 17,291.8 tokens (3.7x more than event_frames_log)
   - Prone to hallucinations despite full video access
   - Worst cost-efficiency: 252.8 tokens per accuracy point

4. MIDDLE PERFORMERS: keyframes_log methods
   - Nearly identical accuracy: 75.5% vs 75.4%
   - Parsed version slightly more accurate
   - Both use moderate token amounts
   - Unparsed version uses ~7% more tokens with minimal accuracy difference

================================================================================
COMMON ERROR PATTERNS
================================================================================

Across all methods, the following errors were frequent:

1. Legend Misidentification
   - Player character incorrectly identified (e.g., Loba, Seer, Octane 
     instead of actual Sparrow/Valkyrie)
   - Most common in raw_video method

2. Weapon Confusion
   - R-301 vs R-99 (most frequent)
   - CAR vs R-99
   - Bocek Bow hallucinations

3. Hallucinated Elements
   - Wattson fences (not present)
   - Gibraltar domes (not visible)
   - Phoenix Kits (never used)
   - Blue energy columns
   - Phase Runner portals

4. Statistical Errors
   - EVO/damage numbers incorrect
   - Squad counts wrong (e.g., claiming 15 when showing 3)
   - Kill counts misreported

5. Teammate Status Errors
   - Missing RESPAWNING states
   - Missing DELIVER TO BEACON indicators
   - Incorrect alive/dead assessments

================================================================================
RECOMMENDATIONS
================================================================================

For Production Use:
1. PRIMARY: Use event_frames_log method
   - Best accuracy (78.1%)
   - Lowest cost (4,653.5 avg tokens)
   - Most reliable and consistent
   - Requires: Frame selection algorithm + log parsing

2. BACKUP: Use keyframes_log_parsed method
   - Good accuracy (75.5%)
   - Moderate cost (5,861.1 avg tokens)
   - Performs well when event_frames_log has issues
   - Requires: Keyframe extraction + log parsing

3. AVOID: raw_video method for production
   - Lowest accuracy (68.4%)
   - Highest cost (17,291.8 avg tokens - 3.7x more expensive)
   - Frequent hallucinations
   - Only use if log data completely unavailable

For Development/Testing:
- keyframes_log_unparsed can be useful for rapid prototyping
- Minimal difference between parsed/unparsed log formats
- Consider parsed version for slightly better accuracy

================================================================================
CONCLUSION
================================================================================

The event_frames_log method is the clear winner for production deployment:

✓ Highest accuracy (78.1%)
✓ Lowest cost (4,653.5 avg tokens)
✓ Best cost-efficiency (59.6 tokens per accuracy %)
✓ Most consistent across different video scenarios
✓ Achieved perfect 100% accuracy on one video

The combination of selective frame extraction with parsed log data provides
optimal results while minimizing token usage. The raw_video method, despite
having access to complete video information, performed worst due to:
- Increased hallucinations from processing too much visual data
- Higher token costs from analyzing 159-184 frames
- No structured data to ground the AI's interpretations

For best results: Invest in frame selection algorithms and log parsing
infrastructure to support the event_frames_log approach.
